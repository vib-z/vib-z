# Ideas

A capture log. The rule: an idea gets written down, researched, and parked here — so it can be
picked up and worked on later if it earns it. Implementation is optional; capture is not.

Each idea gets a folder under [`ideas/`](ideas/) with at least:

- `README.md` — the idea itself, captured while the view of it is still clear
- `research.md` — prior art and feasibility findings, once research has been done
